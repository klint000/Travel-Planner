# Travel Planner

## Описание выполненной работы
В рамках практической работы №16 реализована клиентская часть для отображения данных в формате карточек с изображениями.

В проект добавлена страница `CatalogPage.xaml`, на которой:
- используется `ListView` с `ItemsPanel` на базе `WrapPanel` для построения сетки карточек;
- загружаются данные поездок из таблицы `dbo.trips` базы данных SQL Server;
- в карточке отображаются изображение (из `BLOB` поля `image`, при отсутствии или некорректных данных используется заглушка), название поездки, краткое описание, а также дополнительные визуальные признаки: рейтинг, длительность, сложность и бюджет;
- применяются стили и цветовая палитра из `App.xaml` (наследие практической работы №14).

Также реализована навигация:
- после успешного входа на `LoginPage` пользователь переходит на страницу каталога;
- после успешной регистрации на `RegistrationPage` пользователь переходит на страницу каталога.
