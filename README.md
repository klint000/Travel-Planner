# Travel Planner

## Описание выполненной работы
В рамках практической работы доработано клиентское WPF-приложение `Travel Planner` и реализовано полноценное управление записями каталога поездок (CRUD), а также поиск, фильтрация и сортировка.

В проекте обновлена страница `CatalogPage.xaml`, на которой:
- используется `ListView` с `ItemsPanel` на базе `WrapPanel` для построения сетки карточек;
- загружаются данные поездок из таблицы `dbo.trips` базы данных SQL Server;
- в карточке отображаются изображение (из `BLOB` поля `image`, при отсутствии или некорректных данных используется заглушка), название поездки, краткое описание, а также дополнительные визуальные признаки: рейтинг, длительность, сложность и бюджет;
- добавлена панель инструментов с кнопками:
  - `Добавить` — открытие формы создания записи;
  - `Редактировать` — открытие формы изменения выбранной записи;
  - `Удалить` — удаление выбранной записи с подтверждением;
- добавлен поиск по названию (`TextBox`) с мгновенным обновлением списка;
- добавлены фильтрация по уровню сложности (`Все`, `Легко`, `Средне`, `Сложно`) и сортировка:
  - поле сортировки: `Название`, `Дата начала`, `Бюджет`;
  - направление: `По возрастанию` / `По убыванию`;
  - список обновляется сразу при изменении параметров;
- применяются стили и цветовая палитра из `App.xaml` (наследие практической работы №14).

Добавлено отдельное окно `AddEditPage.xaml` для добавления и редактирования поездок:
- поля для всех атрибутов сущности `trips`: `user_id`, `name`, `start_date`, `end_date`, `budget`, `image`;
- загрузка изображения с диска и отображение превью;
- кнопки `Сохранить` и `Отмена`;
- валидация ввода:
  - обязательные поля (`user_id`, `name`, даты);
  - проверка корректности числовых значений бюджета;
  - проверка, что дата окончания не раньше даты начала;
- сохранение изменений в БД без перезапуска приложения.

В `DatabaseService` реализованы операции:
- `AddTrip` (Create),
- `GetTripCatalogItems` / `GetTripById` (Read),
- `UpdateTrip` (Update),
- `DeleteTrip` (Delete).

Дополнительно добавлена безопасная обработка изображений: при повреждённых или неподдерживаемых байтах изображения превью не отображается, но приложение продолжает работу без падения.

Также реализована навигация:
- после успешного входа на `LoginPage` пользователь переходит на страницу каталога;
- после успешной регистрации на `RegistrationPage` пользователь переходит на страницу каталога.
