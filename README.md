\# Travel Planner — Планировщик путешествий



\## Описание предметной области



База данных предназначена для организации и документирования личных и деловых поездок. Система позволяет:



\- Планировать маршруты с учетом времени и бюджета

\- Хранить цифровые копии документов (паспорта, визы, страховки)

\- Отслеживать статус бронирований (отели, билеты, экскурсии)

\- Формировать ежедневные планы посещения достопримечательностей

\- Вести фотоотчеты и заметки о поездке

\- Контролировать расходы с разбивкой по категориям



\## Ключевые бизнес-сущности



| Таблица | Назначение |

|---------|------------|

| `users` | Пользователи системы |

| `trips` | \*\*Ядро системы\*\* — путешествия (120+ записей) |

| `routes` | Маршруты по дням |

| `route\_items` | Элементы маршрута (достопримечательности) |

| `bookings` | Бронирования (отели, билеты) |

| `expenses` | Расходы с категориями |

| `travel\_notes` | Заметки и фотоотчеты |

| `documents` | Цифровые копии документов |

| `attractions` | Справочник достопримечательностей |



\## Роли и права доступа



| Роль | Права |

|------|-------|

| \*\*User\*\* | Просмотр и создание своих поездок, добавление расходов, заметок |

| \*\*Manager\*\* | Управление поездками всех пользователей, формирование отчетов |

| \*\*Admin\*\* | Полный доступ: управление пользователями, справочниками, всеми данными |
