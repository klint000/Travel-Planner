# Travel Planner WPF

## Описание выполненной работы

Разработана клиентская часть информационной системы по предметной области `travel_planner` из практической работы №13. В проекте реализованы:

- Окно авторизации `LoginPage.xaml` с логотипом, полями логина/email и пароля, кнопкой входа и ссылкой перехода к регистрации.
- Окно регистрации `RegistrationPage.xaml` с логотипом, заголовком, полями ФИО, Email, Логин, Пароль, Подтверждение пароля.
- Переход между окнами авторизации и регистрации через обработчики событий.
- Проверка совпадения пароля и подтверждения пароля при регистрации.
- Подключение к базе данных SQL Server `travel_planner`.
- Реальная регистрация пользователя в таблицу `users` и сохранение защищенных учетных данных в `user_credentials` (`salt + password_hash`).
- Реальная авторизация по `username/email + password` с проверкой хэша пароля.
- Централизованные стили, цвета и шрифты в `App.xaml` (`Application.Resources`).
- Фирменные ресурсы интерфейса: `logo.png` и `app.ico`.

Использованная палитра:

- Фон: `#FFE3F2FD`
- Акцент: `#FF0097A7`
- Дополнительный цвет: `#FFFF9800`
- Шрифт: `Segoe UI`
